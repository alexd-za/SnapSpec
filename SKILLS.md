# Skills

12 skills live in `.claude/skills/<name>/SKILL.md`. Each has YAML frontmatter, a trigger, procedure, checklist, and output format.

| Skill                 | Use for                                                                                                                         |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `/snap-nature-design` | Creating/reviewing the nature UI: palettes, layout, hover/focus, empty states. Blocks purple-gradient clichés and dead buttons. |
| `/snap-motion`        | Animations + loading states: intro, transitions, skeletons, cascade, flips, bloom, reduced-motion.                              |
| `/snap-parser`        | Parser rules and extractors; keeps the deterministic rule set true and tested.                                                  |
| `/snap-poetry`        | Poetry-analysis quality: technique → effect → meaning, quote analysis, thesis, outline.                                         |
| `/snap-maths`         | Formula detection, worked examples, mistakes, practice questions (trig/functions/algebra/calculus/geometry).                    |
| `/snap-product`       | Product briefs and showcases: problem-first structure, roadmap timelines, launch teaser.                                        |
| `/snap-svgz`          | The 40-asset SVG/SVGZ pipeline: generation, SVGO, gzip, manifest, validation.                                                   |
| `/snap-export`        | Export formats: Markdown/HTML/JSON/SVG/SVGZ/revision pack/static site, escaping, round-trips.                                   |
| `/snap-video`         | Remotion compositions and rendering; honest fallback to preview frames.                                                         |
| `/snap-a11y`          | Accessibility pass: keyboard, focus, contrast, aria, semantics, mobile, reduced motion, forms, errors.                          |
| `/snap-test`          | Run lint → unit → build → E2E → asset check; triage failures by first error line.                                               |
| `/snap-ship`          | Final release checklist; produces the build report.                                                                             |
